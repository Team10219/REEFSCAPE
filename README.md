# FRC Team 10219 - 2025 Robot Code

Welcome to the 2025 season codebase for **FRC Team 10219 - Bathtub Chickens**. This repository contains the software for our swerve-drive robot using AdvantageKit for logging and replay, and MapleSim for realistic physics simulation.
